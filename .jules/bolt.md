## 2024-05-24 - Zero-Server Main Thread Sensitivity & Layout Thrashing
**Learning:** In a 'Zero-Server Real-Time Sync' architecture where the host browser acts as the central server (handling concurrent student connections via WebRTC, MQTT, and BroadcastChannel), the main thread is highly sensitive to synchronous bottlenecks. Iteratively appending elements to the DOM inside loops (e.g., during high-volume events like 30 students joining the lobby simultaneously or updating large leaderboards) causes severe layout thrashing and blocks the main thread, potentially dropping network connections.
**Action:** Always use `DocumentFragment` to batch DOM node creations and insertions for lists, tables, and collections. Append all children to the fragment in memory, then append the fragment to the live DOM exactly once.
