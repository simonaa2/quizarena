## 2026-10-10 - Use DocumentFragment for Batch DOM Insertions\n**Learning:** The application's "Zero-Server Real-Time Sync" architecture heavily burdens the host browser's main thread, making it highly sensitive to synchronous performance bottlenecks. Iterative DOM manipulations using `.appendChild()` inside loops can cause layout thrashing and stuttering.\n**Action:** Always use `DocumentFragment` to batch DOM node creations and insertions, avoiding iterative DOM manipulation.
